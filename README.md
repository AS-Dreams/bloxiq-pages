# Bloxiq App Store Pages

Static GitHub Pages files for Bloxiq Block Puzzle.

Recommended public repository:

`AS-Dreams/bloxiq-pages`

Recommended App Store Connect URLs after GitHub Pages is enabled:

- Privacy Policy URL: `https://as-dreams.github.io/bloxiq-pages/privacy.html`
- Support URL: `https://as-dreams.github.io/bloxiq-pages/support.html`

GitHub Pages setup:

1. Create a public repository named `bloxiq-pages`.
2. Upload all files from this folder to the repository root.
3. Open repository Settings > Pages.
4. Set Source to `Deploy from a branch`.
5. Set Branch to `main` and folder to `/root`.
6. Save and wait until GitHub shows the published site URL.
